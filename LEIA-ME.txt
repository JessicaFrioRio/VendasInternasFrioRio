SITE FRIORIO - VENDAS PARA COLABORADORES
========================================

ARQUIVOS (todos na mesma pasta):
  index.html    -> página inicial (banners + cards de políticas)
  pedido.html   -> página do formulário (banners 3 e 4 rotativos)
  style.css     -> todo o visual (cores no topo do arquivo)
  script.js     -> carrossel + LINK DO FORMULÁRIO (1a linha editável)
  Imagens que VOCÊ coloca na pasta: logo-empresa.png, banner1.png,
  banner2.png, banner3.png, banner4.png

COMO VER: dê dois cliques no index.html.

CPFs LIBERADOS E LINK DO FORMULÁRIO: abra api/_dados.js (um CPF por linha, e o FORM_URL).
  Mantenha o repositório do GitHub PRIVADO, pois a lista fica nele.

TROCAR TEXTOS: abra o .html no Bloco de Notas/VS Code e edite o texto.

GIT + VERCEL:
  git init
  git add .
  git commit -m "Site de vendas para colaboradores"
  git branch -M main
  git remote add origin URL_DO_REPOSITORIO
  git push -u origin main
  Na Vercel: Add New > Project > escolha o repositório > Deploy
  (Framework Preset: Other; não precisa de build).

TAMANHO DOS BANNERS: 1920 x 600. Para outro tamanho, edite --proporcao-banner no style.css.
